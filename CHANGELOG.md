# Changelog

All notable changes to IP Intelligence are documented here.

## Mobile v1.0.1 — 2026-11-28

- Integrated the map inside the Flutter app: location preview in the results plus a full-screen in-app map with zoom controls. The Map button no longer opens a browser.
- Published as a GitHub Release APK for direct Android installation.

## Mobile v1.0.0 — 2026-11-27

- First Flutter mobile app release (Android APK on GitHub Releases): My IP detection, IP lookup, VPN/proxy/Tor detection, DNS/RDAP/ASN tools, and local history.

## Web — 2026-11-27

- Added the VPN, Proxy & Anonymity Detection Engine with transparent confidence states (Detected / Not Detected / Likely / Unknown / Inconclusive), Tor exit-node checks, and Compare My Connection snapshots.
- Added IPv4/IPv6 connectivity detection, IP comparison, Privacy & Leak Tests with a transparent Privacy Score, and the Browser Fingerprint Lab.
- Initial public release: IP lookup with ipapi.co + ipwho.is, Leaflet/OpenStreetMap map, DNS-over-HTTPS diagnostics, RDAP and ASN lookups, and local lookup history.
